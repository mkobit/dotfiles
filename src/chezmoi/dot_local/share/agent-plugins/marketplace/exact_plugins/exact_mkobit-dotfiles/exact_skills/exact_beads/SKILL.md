# Beads

Beads (`bd`) is a local issue tracker with dependencies and version history.
See the [official documentation](https://github.com/gastownhall/beads/tree/main/docs).
Use `bd version`, `bd --help`, and `bd <command> --help` to check the installed version and available commands.
Use `bd ready`, `bd list`, and `bd show ID` to inspect work.
Check the installed version's help for sync flags.
The command grants cover the local issue lifecycle and `bd dolt push`.
Other commands use the host approval policy.
Claude and Antigravity deny `bd upgrade`.
